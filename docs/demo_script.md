# 3-minute demo video script

Record with any screen recorder (OBS Studio is free). Upload to YouTube and link it from the README.

| Time | Show | Say |
| --- | --- | --- |
| 0:00-0:20 | Title slide or README top | The problem, and who has it, in one sentence. |
| 0:20-1:30 | Live app: 2 or 3 realistic questions, including one hard one | What's happening, and point at the cited sources. |
| 1:30-2:10 | Architecture diagram | The 3 or 4 main components and the one key design decision. |
| 2:10-2:40 | Eval results table | How you measured quality, and what improved. |
| 2:40-3:00 | Repo and contact | What you'd build next; where to find the code. |

Tips: rehearse once; increase the font size; use realistic questions; show one failure honestly and explain how the evals caught it.
