# Data governance

Data governance defines who owns each dataset, how it may be used, and how its quality is measured. A data steward is responsible for the quality and documentation of a dataset.

A data catalog lists datasets with their metadata, such as owner, description, sensitivity and lineage. Lineage shows where data came from and which systems transform it.

Personal information must be classified and protected. Access to sensitive datasets should follow the principle of least privilege, and every access should be logged for audit.

A model card documents what a machine learning model is for, how it was evaluated, and its known limitations. A data card does the same for a dataset.
