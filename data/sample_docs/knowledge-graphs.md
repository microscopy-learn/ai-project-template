# Knowledge graphs

A knowledge graph stores facts as entities connected by typed relationships. Each fact can be read as a subject, a predicate and an object, which is the triple model used by RDF.

An ontology defines the classes, properties and constraints that give a knowledge graph its meaning. OWL is the W3C language for writing ontologies, and SKOS is the W3C standard for taxonomies and thesauri.

SPARQL is the query language for RDF graphs. Cypher is the query language used by Neo4j and other property-graph databases.

SHACL shapes validate a graph against rules, for example that every dataset must have exactly one owner. Validation failures are reported as a SHACL validation report.
